Project Description:

Developer Portfolio is a front-end web project that acts as a personal online portfolio for a web developer. The website contains dedicated sections for About Me, Technical Skills, Creative Skills, Education, Projects, and Contact, allowing visitors to easily explore the developer’s background and work.

The About Me section introduces the developer as someone interested in both front-end and back-end development, with a focus on creating interactive and visually appealing websites.

The Technical Skills section presents proficiency in Java, CSS, JavaScript, Python, C++, and C using visual progress bars. The portfolio also includes a Creative Skills section showcasing photography and videography, highlighting how these skills can be used to improve the visual quality of websites.

The Projects section displays four projects through an interactive slider:

Web-based e-commerce platform, Portfolio website with animations, Interactive to-do list application, AI-powered chatbot

JavaScript provides the interactive functionality of the website, including a responsive hamburger navigation menu and a project slider that allows users to move between projects.

The website is also designed to be responsive, with a mobile navigation menu and layouts that adapt to smaller screen sizes.

Technologies Used:

HTML5 – Website structure and content

CSS3 – Layout, styling, animations, skill bars, and responsive design

JavaScript – Mobile navigation and project-slider functionality

Short Description for Project Report:

Developer Portfolio is a responsive personal portfolio website developed using HTML, CSS, and JavaScript. It provides an organized platform to showcase a developer’s personal information, technical and creative skills, educational background, projects, and contact details. The website includes interactive features such as a mobile navigation menu, project slider, hover effects, and responsive layouts, making it accessible across different devices.
